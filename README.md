# 🌌 포천아트밸리 천문과학관 : 우주 타로 (Space Tarot)

> **"별이 당신에게 전하는 오늘의 이야기"**  
> 포천아트밸리 천문과학관의 고품격 전시물로서, 관람객에게 우주의 신비와 타로의 지혜를 결합한 특별한 경험을 제공하는 키오스크 애플리케이션입니다.

---

## ✨ 주요 특징 (Premium Features)

### 1. 🚀 고품격 시각 연출 (High-End UX/UI)
*   **스플래시 화면**: 성운(Nebula) 효과와 플로팅 애니메이션이 적용된 프리미엄 진입 화면.
*   **반응형 디자인**: `dvh` 및 유연한 그리드 시스템을 통해 세로형 키오스크부터 태블릿까지 완벽한 레이아웃 제공.
*   **시네마틱 애니메이션**: 블랙홀 진입 효과, 유성우, 카드 글로우 등 몰입감을 극대화하는 시각 효과.

### 2. 🔌 100% 오프라인 동작 (Fully Offline Capable)
*   **로컬 자원 관리**: Google Fonts 및 외부 라이브러리(QRCode.js)를 모두 로컬로 번들링하여 인터넷 연결 없이도 동작.
*   **코드 사운드 합성**: 외부 MP3 파일 없이 **Web Audio API**를 통해 실시간으로 사운드를 합성하여 재생.

### 3. 🔭 교육용 콘텐츠 (Educational Contents)
*   **천문학 지식**: 23종의 카드마다 별자리의 과학적 특징, 행성의 천문학적 정보 등 교육적 메시지 포함.
*   **타로의 지혜**: 각 카드의 상징적 의미와 조언을 1-2줄로 간결하고 깊이 있게 전달.
*   **수동 학습 모드**: 사용자가 정보를 충분히 읽을 수 있도록 터치 기반의 수동 진행 방식 채택.

### 4. 🔊 사운드 엔진 (Sound Engine)
*   **물리적 피드백**: 카드 뒤집기(Flip), 슬롯 안착(Pop), 결과 발표(Chime) 등 상황에 맞는 사운드 생성.
*   **Cosmic Drone**: 내러티브 화면에서 흐르는 은은한 우주의 기운을 코드로 구현.

---

## 🧠 시스템 로직 (System Logic)

### 1. 운명 결정 알고리즘
사용자의 생일과 현재 시간을 결합하여 고유한 '운명의 씨앗'을 생성합니다.
*   **역위치(Reversed) 판별**: `(생일 + 오늘날짜) % 10` 값이 8 이상일 경우 세 번째 카드(Element)가 역방향으로 작용합니다.

### 2. 3단계 선택 프로세스
1.  **Zodiac (별자리)**: 타고난 기질과 성향을 상징.
2.  **Planet (행성)**: 현재 삶에 영향을 미치는 에너지의 파동.
3.  **Element (원소)**: 본질을 구성하는 근본적인 우주적 에너지.

### 3. QR 결과 공유
오프라인 키오스크 환경에서도 결과 페이지(`Cloudflare Workers` 배포본)로 연결되는 고유 QR 코드를 생성하여 관람객의 모바일 기기로 결과를 소장할 수 있게 합니다.

## 📂 프로젝트 구조

```text
tarot/
├── index.html       # 메인 인터페이스, CSS 애니메이션, 사운드 엔진, 핵심 로직
├── tarot.js         # 수천 개의 운세 조합을 담은 데이터 엔진
├── fonts/           # Noto Sans KR, Orbitron 등 로컬 폰트 자산
├── lib/             # qrcode.min.js (로컬 라이브러리)
├── images/          # 타로 카드 및 UI 이미지 자산 (webp, png)
└── util/            # 데이터 처리 유틸리티
```

*   **Audio**: Web Audio API (Real-time Synthesis)
*   **Graphics**: CSS Keyframes, CSS Filters, SVG
