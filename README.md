# 포천아트밸리 우주 타로 (Pocheon Art Valley Space Tarot)

포천아트밸리를 방문하는 관람객들을 위한 고품격 우주 테마 타로 키오스크 애플리케이션입니다. 사용자의 생년월일과 우주의 기운(Zodiac, Planet, Element)을 결합하여 개인화된 운세 결과를 제공합니다.

## 🌟 주요 특징

- **프리미엄 디자인**: 다크 모드 기반의 세련된 우주 테마 UI와 부드러운 애니메이션(블랙홀, 유성우 등)을 적용하여 몰입감 있는 경험을 제공합니다.
- **3단계 카드 선택**: Zodiac(황도 12궁), Planet(행성), Element(원소)를 순차적으로 선택하여 수천 가지 조합의 운세를 생성합니다.
- **시네마틱 연출**: 카드 선택 및 결과 도출 과정에서 역동적인 시각 효과와 텍스트 연출을 통해 신비로운 분위기를 조성합니다.
- **결과 공유**: 운세 결과를 QR 코드로 생성하여 스마트폰으로 쉽게 소장할 수 있습니다.

## 🧠 운세 알고리즘 (Algorithm)

본 애플리케이션은 사용자의 생일과 현재 시간을 우주의 기운과 결합하여 운세를 산출합니다.

### 1. 역방향(Reversed) 판별 로직
사용자의 생일과 오늘 날짜를 더한 값의 나머지를 이용해 카드의 정/역 방향을 결정합니다.
- **계산식**: `(생일(MMDD) + 오늘 날짜(YYYYMMDD)) % 10`
- **결과**: 값이 `8` 이상이면 **역방향(역)**, `7` 이하이면 **정방향(정)**으로 판별됩니다.
- **예시 (5월 14일생, 2026년 5월 3일 기준)**:
    - `0514 + 20260503 = 20261017`
    - `20261017 % 10 = 7` (7 ≤ 7 이므로 **정방향**)

### 2. 3단계 카드 선택 (User Selection)
사용자는 화면에 배치된 카드 중 직관에 따라 3장을 직접 선택합니다.
- **1단계 (Zodiac)**: 12가지 별자리 중 하나 (예: 양, 전갈, 물병 등)
- **2단계 (Planet)**: 7가지 행성 중 하나 (예: 태양, 화성, 목성 등)
- **3단계 (Element)**: 4가지 원소 중 하나 (예: 불, 물, 공기, 흙)

### 3. 최종 운세 매칭 (Data Matching)
선택된 카드들과 판별된 방향을 조합하여 최종 키(Key)를 생성하고 `tarot.js`에서 해당 데이터를 찾아 출력합니다.
- **최종 키 예시**: `양-태양-불(정)`
- **데이터 구조**: `tarot.js` 내의 수천 가지 조합 중 생성된 키와 일치하는 `card` 속성을 가진 데이터를 매칭하여 제목(`title`)과 내용(`content`)을 표시합니다.

## 📂 프로젝트 구조

```text
tarot/
├── index.html       # 메인 인터페이스 및 핵심 로직, CSS 애니메이션

    └── crawler.py   # 운세 데이터 수집 및 정리를 위한 유틸리티 스크립트
```

## 🚀 사용 방법

1.  **시작 화면**: 키오스크 화면에서 안내에 따라 생년월일(월, 일)을 선택합니다.
2.  **운명의 선택**:
    -   **1단계 (Zodiac)**: 자신의 기질을 상징하는 황도 12궁 카드를 선택합니다.
    -   **2단계 (Planet)**: 현재의 흐름을 상징하는 행성 카드를 선택합니다.
    -   **3단계 (Element)**: 근본적인 에너지를 상징하는 원소 카드를 선택합니다.
3.  **운세 확인**: 선택된 조합에 따라 생성된 '우주 타로' 결과를 확인합니다.
4.  **결과 저장**: 화면 하단에 생성된 QR 코드를 스캔하여 결과를 스마트폰에 저장할 수 있습니다.
